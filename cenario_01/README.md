# Cenário 01 — Segmentação por VLANs, Roteamento Inter-VLAN e DHCP Distribuído

## 🎯 Objetivo
Configuração de infraestrutura de rede corporativa segmentada via VLANs em comutadores Cisco, com roteamento Inter-VLAN no modelo *router-on-a-stick* e distribuição dinâmica de endereços IPv4 via servidores DHCP locais configurados nos switches de acesso.
